# Merlin

An AI health coach that texts me on Telegram. It pulls my sleep, recovery, and workout data from Whoop and uses it to check in, answer questions, and keep me accountable.

It runs 24/7 on an AWS server using OpenClaw, with a custom skill for the Whoop API.

This repo has the project notes, not the server code:

- `docs/merlin-project-handoff.md`: how it's set up and known issues
- `docs/merlin-proactive-triggers.md`: plan for having it message me first (not built yet)
